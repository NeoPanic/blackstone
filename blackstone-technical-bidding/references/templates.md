# 投标交付表格

有项目规定格式时优先使用项目表。内部工作表可以根据规模合并。对扫描件定位 PDF 页并记录原文页码，页码不一致时同时保留两个位置。

| 表 | 字段 |
| --- | --- |
| 机会和取件卡 | 项目编号、包号、公告状态、发布和交易入口、采购范围、预算与限价、资格、取件期限、递交期限、文件版本、取件状态及凭证。 |
| 项目规则卡 | 采购主体、资金与项目类型、采购方式、适用制度、项目文件和版本、主管部门、关键期限及原文位置、待澄清事项。 |
| 参投与计划表 | 包号、参投判断、资格缺口、可举证评分项、履约和成本约束、负责人、补齐期限、决策人及时间。 |
| 响应矩阵 | 条款编号、原文、文件版本与位置、条款类别、要求及后果、逐项答复、偏离、证据编号和定稿页、责任人及状态。 |
| 证据台账 | 证据编号、来源、主体和时间、有效期、关联条款、文件与页码、是否允许随标提交、复核状态。 |
| 澄清与补遗记录 | 条款、公开问题或文件矛盾、提交时限及渠道、答复或更正来源、影响的文件与期限、处理结果。 |
| 终审清单 | 包号、级别、条款或交叉校核项、文件和页码、问题、整改、复核人和状态。 |
| 递交与开标台账 | 包号、最终版、签章加密状态、渠道、递交时间及回执、开标解密结果、澄清窗口、归档位置。 |
| 结果及救济记录 | 公告、公示或通知及时间、事项、适用程序和受理方、条文与截止日、请求、事实、证据、处理状态。 |

未取得结果的过程字段写待确认，并用真实的文件或回执更新状态。面向采购人的投标文件仅按要求提交正式版本，内部审稿批注与成本测算按适用要求控制披露。
