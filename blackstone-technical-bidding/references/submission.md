# 终审、递交、开标与结果跟进

## 审到最终提交件

1. **程序与否决风险**。由条款反查每项资格、实质性响应、签章、授权有效期、保证金、限价、包号、电子格式和匿名要求，在导出的实际文件中定位证据。
2. **商务和技术交叉核对**。校验交付、版本、型号、数量、日期、服务标准、偏离、报价总表和明细。将技术承诺逐项核到成本、交付和验收范围。
3. **评分证据核对**。反查漏答、附件错误、证明时间窗口和评分条件。对主观档次提供有证据的评估范围。终审按递交阻断、扣分风险、履约风险、文字问题排序，记录整改证据和复核人。
4. **生成递交版**。锁定文件基线，并记录各包文件、版本、签署状态及生成时间。签章或加密后复验平台可读取性、文件完整性和附件。平台有自检时保存结果。发现正式更正在截止前发布时，回到响应矩阵评估影响并核对是否需要撤回重提。

## 递交与开标

- 线上按项目规定使用指定平台和工具，核对账号主体、电子签章、加密及同一证书解密要求。为上传、重提、开标登录和解密预留时间。记录提交成功状态、服务器时间、回执和版本。上传进度、签章成功、正式递交是不同状态。
- 线下按指定地点、交接人、密封与份数交件，记录收件凭证。联合体、分包或多包件核对提交主体和逐包回执。
- 发生平台故障、解密异常或回执不明时保存时间、错误信息、回执状态和平台工单。依据交易平台规则及招标文件区分故障原因与处置，按正式通知核对是否重提、延期或进入其他流程。
- 参加开标、演示、样品检查或澄清时留存相关记录。政府采购谈判或磋商跟踪书面变动和最后报价通知，询价按适用规则一次报出报价。收到澄清要求时按允许范围匹配原投标响应和出处，留存问答与期限。
- 收到谈判或磋商的书面变动时，重算其对资源、工期、合同草案与原报价的影响，把新响应和最后报价比对后再递交。核对签字主体、提交入口、允许提交的时间和收到凭据。保留各轮报价和随附说明以便追溯。

## 结果、救济与合同交接

- 核对候选人公示或中标成交公告、包号、价格和中标通知书。按适用规则追踪保证金退还和履约担保。中标后逐项移交投标承诺、合同条款、报价、验收和履约证据给交付团队。
- 对结果或文件存在疑点时先建立事实时间线。政府采购按《政府采购法》及财政部令第94号走质疑与投诉。供应商一般在知道或应知权益受损之日起7个工作日内提出质疑，答复期限届满后的投诉期限一般为15个工作日。核对供应商资格、采购文件是否依法获取、具体起点和受理机关。
- 招标投标体系按适用规则处理投标人或利害关系人的异议与投诉。依法必须招标项目评标结果异议在中标候选人公示期提出。对招标文件、开标和评标结果的投诉涉及法定异议前置时，分别登记入口、起算点和异议答复期间。核实当地及行业的受理渠道。
- 归档公告和文件版本、内部决策及授权、定稿与回执、开标澄清、结果及合同交接。登记复盘中可复用的证据及有效期，内部价格和客户非公开材料按授权范围归档。[投标适用规则及官方来源](rules.md)
