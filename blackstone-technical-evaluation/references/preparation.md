# 评标办法制定与评前准备

## 发文件前审评标办法

1. 把采购目标落成能验收的性能、服务水平、交付物与合同条件。分别确定资格审查、实质性条款和评分因素的用途。第87号令的综合评分法将资格条件排除在评分因素之外。
2. 根据项目需求和制度选适用方法。政府采购中技术、服务等标准统一的货物服务项目，按适用规则使用最低评标价法。依法适用招标投标制度的，按规定与项目特性确定经评审的最低投标价法、综合评估法或其他合法方法。
3. 细化评分表。每项写条款编号、指标、满分、计分或折算公式、得分档次及证据。主观项把评价锚点落在实际内容，如割接方案能否给出回退触发条件、负责人与验证方式。审查档次重叠、上下界、重复计分、总分和异常输入。核对报价调整、政策扣除、并列和舍入规则。
4. 逐条核对采购需求、评分、投标格式和验收口径。检查地域、规模、特定品牌、与本项目无关的业绩要求等限制竞争的条件，发现问题由正式程序修订。结合适用规则写明可接受的等效证明。仅在正式发出前或法定变更程序中调整评分规则。

## 发文件后锁定评标依据

- 收集生效招标文件及全部补遗、评标表、开标记录、接收回执、投标文件与平台日志。区分有效提交、替换、撤回及解密状态，记录具体包号。评审中发生版本争议，先查平台时间戳及正式通知。
- 按适用规定核对人数及构成、专家抽取或依法例外、专业覆盖、回避和替补。政府采购货物服务招标的第87号令规定评委会应为5人以上单数、评审专家不少于成员总数的三分之二。采购预算金额在1000万元以上、技术复杂或社会影响较大的，评委会应为7人以上单数。招标投标制度中的法定组成要求按其规则单独核对。[财政部令第87号第四十七条](https://tfs.mof.gov.cn/caizhengbuling/201707/t20170718_2652603.htm)
- 组织方介绍适用程序、公布的规则、回避、保密和纪律，分发同一版本资料。评审成员各自按规则审查、独立评分并留痕。出现缺员、回避或无法继续时，按适用程序及平台规定处置并记录。
- 按评审权限准备工作区、匿名解码控制、价格信息开启阶段、书面澄清通道和留档。正式评审的非公开材料仅在项目授权的评审环境使用。
