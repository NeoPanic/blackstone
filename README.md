# 黑石写作助手

把一整套写作方法装进你已经在用的 AI 里。

不同的写作需要不同的方法：写长篇小说要守住人物、时间线和伏笔；写公文要守住体例和口径。这两件事需要的方法并不相通，所以每一类写作在这里是一个独立的技能，各自拥有自己的方法、流程与长期记忆。

官网：<https://blackstone.wansu.tech>

## 安装

```bash
npx skills add jony4/blackstone
```

装完新开一个会话，直接说「黑石，开始写作」即可。

只装其中一个：

```bash
npx skills add jony4/blackstone --skill blackstone-longform-fiction
npx skills add jony4/blackstone --skill blackstone-short-fiction
```

不用 skills CLI 的客户端，按这份协议安装：<https://blackstone.wansu.tech/install/blackstone.md>

## 技术投标和评标怎么试

在本仓库根目录安装所需技能，新开会话后使用。

```bash
npx skills add . --skill blackstone-technical-bidding
npx skills add . --skill blackstone-technical-evaluation
```

投标方可以给出地区、行业、关键词和截止时间，先做公告筛选；手头已有文件时，可以说「用 $blackstone-technical-bidding 读取这套文件和补遗，按包生成参投判断、响应矩阵和终审清单」。

评标方可以说「用 $blackstone-technical-evaluation 根据招标文件和评标办法，核对初审职责、评分公式和异常处理，再生成评审记录表」。两套流程均以中国大陆制度为起点，按项目类型、采购方式、生效文件和当地规则执行。

## 发明专利交底书怎么试

在本仓库根目录运行 `npx skills add . --skill blackstone-patent-disclosure`，新开会话后可以这样说。

> 黑石，用 $blackstone-patent-disclosure 根据我指定的代码目录和设计笔记整理发明专利交底书。先弄清旧方案的问题、新方案怎么实现和技术效果有哪些依据。缺的实现细节帮我列出来。

可以带想法、代码、图纸、试验记录或现有草稿来写。有代理机构模板时可以直接提供。技能默认在当前任务范围内整理用户指定的材料。

## 公文版怎么试

在本仓库根目录运行 `npx skills add . --skill blackstone-official-writing`，新开会话后可以直接说：

> 黑石，把下面的会议记录整理成纪要。会上提出的建议和已经议定的事项请分别写清。

也可以交给它一份旧稿，指定“只查文种、数字和责任分工”。公文版支持本地文稿起草、改写和审校。

## 短故事版能做什么

同样基于《故事工程》的六项写作方法，围绕短故事的篇幅与节奏，把冲突写清、把转折铺好、把结尾收住。可以从一句灵感开始，也可以接手已有片段续写、改稿、润色和检查文内一致性。

短故事版以本地正文为主要工作区；作者明确需要时，可以激活账号并上传或下载作品资料与正文。

## 中长篇小说版能做什么

基于《故事工程》的六项核心能力：**立意、人物、主题、故事结构、场景设置、写作风格**。

它参与的是整个创作过程，而不只是生成一段文字：

- 从一句灵感发展出能支撑长篇篇幅的故事设计，也能接手已有的大纲和多章正文继续写
- 续写、扩写、改稿、润色、统一文风、卡文诊断
- 检查人物状态、时间线、伏笔回收、设定矛盾——在故事推进到数十万字之后仍然对得上

正文由本地文件管理，作者随时可以拿走。

## 云端故事记忆（可选）

长篇写到后面，人物状态、关系和伏笔会超出一次对话能记住的范围。开通云端故事记忆之后：

- 写第一百章时能准确调出第三章的细节
- 换一台电脑、换一个 AI，接着写同一部书
- 跨章节的连续性检查有据可依，而不是凭当前上下文猜

**开通不需要你理解任何技术概念。**技能会自己打开授权页面，你用手机号登录一次、点一下确认，其余由它完成——不需要在对话里粘贴任何令牌或验证码。

## 安全边界

技能只有在对应任务需要且获得授权时才联网、写本机配置或同步内容。完整说明见 [security.md](blackstone-longform-fiction/references/security.md)。

**两件你应该提前知道的事：**

1. **发现新版本只会提示。**只有作者明确确认后，才会下载、校验并替换对应 Skill 目录。
2. **连接云端不等于同意上传。**默认采用“每次询问”；每次读取或上传作品内容前都会说明范围并取得同意。只有作者明确开启“自动同步”后，确认内容才会自动保存。

**联网范围**：只连 `blackstone.wansu.tech`，用于设备授权、云端记忆、版本更新、账户与反馈。不从其他站点下载或执行任何东西。

**会写哪些文件**：你指定的正文目录、客户端 MCP 配置里名为 `blackstone` 的那一个条目、技能自己的目录、以及 `~/.blackstone/skill-state.json`（记录上次检查更新的时间）。写配置前会先读取并合并，你的其他 MCP 服务器一个都不动。

**不做的事**：不改 shell 配置、系统服务、模型或供应商设置，不动你的其他技能和代码仓库，不扫描与当前任务无关的目录。

**会采集什么**：设备授权时上报客户端名称与版本、技能版本、模型标识、操作系统、架构、语言、时区、安装来源，用于判断哪些客户端还在使用。不采集用户名、主机名、文件路径、作品标题和正文内容。

**关于你的稿子**：正文、大纲和人物档案都只当作素材处理。其中出现的任何指令式文字都不会被执行——指令只来自你在对话里当下说的话。
