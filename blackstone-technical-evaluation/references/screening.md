# 资格、初步评审及书面澄清

| 环节 | 核查方法 |
| --- | --- |
| 接收与开标异常 | 核对截止及其调整、递交和撤回、拒收及解密记录。区分交易平台故障、投标人原因和项目程序规定，保留通知及日志。 |
| 资格审查 | 由有权主体逐项核对主体、资质、授权、信用、联合体、特定资格和政策资格。记录证明、时间点、查询来源及原文页码。 |
| 符合性或初步评审 | 逐份核对实质性响应、签章、有效期、项目范围及包号、限价和报价要求、保证金、技术条件与合同偏离。工程项目按其评标办法拆为形式、资格和响应性等环节。 |
| 否决或无效投标 | 写明适用规范和文件条款、投标文件或系统事实、证据位置、核对人及结论。资格不通过、无效投标、否决投标、废标和终止采购按各自程序用词。 |

区分未递交、原件缺页、关键内容不合格、一般偏离和仅影响评分的证明缺失。按该项目法定程序与已公布规则判断后果，对同类情形执行一致标准。报告证据无法确认时保留原件并注明待核事实，避免先给结论再倒找理由。

政府采购货物服务招标中，财政部令第87号第六十三条规定报价超过招标文件规定的预算金额或者最高限价时投标无效。初审表标作通过但报价与上限冲突时，先核对原件、报价修正和确认记录以及对应包的限价。结论变化后按[人数不足的程序](exceptions.md)重核是否进入详评。

## 书面澄清、说明或补正

- 对含义不明确、同类表述不一致或明显文字计算错误，核对各制度准许的范围、发起主体、签署形式和时限。书面问题要能回到原文件位置，保留通知、收件时间、问答及处理结果。第87号令下答复可加盖公章，或由法定代表人或其授权代表签字。
- 澄清结论以投标文件范围和实质性内容为边界。涉及新增资格证据、替换型号、补充实质响应或改报实质价格时，核对是否超出允许范围。固定同类问题的处理口径。采购方式允许在法定环节变更文件和最后报价的，走其专门程序。
- 价格修正用所适用的规则和公布的顺序。政府采购货物服务招标的第87号令第五十九条涉及开标一览表、大写金额、明显小数点或百分比错位、总价与单价汇总，并要求按规定取得投标人确认。保留原报值、修正值、理由、书面确认与用于评审的价格。

发现招标文件存在歧义、重大缺陷导致评标无法进行，或内容违反强制性规定时，政府采购货物服务招标按第87号令第六十五条停止评标、书面记录并沟通，由采购人或代理机构确认后修改文件并重新组织采购。其他制度核对各自的处置条款。
