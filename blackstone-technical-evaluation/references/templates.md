# 评标交付表格

按包建立逐条记录。具有法定或平台模板时沿用模板和签署流程。内部明细可附在正式模板之外。

| 表 | 字段 |
| --- | --- |
| 评审规则卡 | 包号、采购方式、适用制度、有效版本、评标方法及公式、责任主体、关键期限、例外处理条款。 |
| 资格或符合性审查表 | 投标人、要求编号、条款原文与位置、提交证据位置、核验事实、结论与理由、责任主体。 |
| 评分明细 | 投标人、评分项及上限、证明及页码、评审人、计算变量或档次、原始分、汇总分、依据和待核事项。 |
| 标价比较表 | 原报价、修正值和确认、政策或商务调整、适用报价集合、评审价、公式及中间值、价格得分或价格排序。 |
| 澄清及异常记录 | 触发条款与证据、问题正文、发出与回复时间、说明及证明、处理过程、是否影响有效性和排序。 |
| 候选人推荐表 | 投标人、原报价和评审价、分项分与汇总、排序与并列依据、是否推荐及理由、异议与签署。 |
| 复核记录 | 触发条款、发现时点、涉及条目、原值、修订值、合法程序、是否改变结果、签署或报告凭据。 |

从排序回溯到计算、分项和原件，再从条款追踪每家投标人的同类处理。有缺页、未签署或未完成核验时，写明真实状态和受影响的结果。
