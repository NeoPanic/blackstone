# 详细评审、价格计算和排序

先保留原始报价、按规则修正后报价、用于评审的价格三列，另存技术商务证据、各委员原始分及汇总值。只把按规则进入详细评审的投标纳入相应计算集合。基准价、异常低价触发、政策扣除和候选排序可能使用不同集合及价格口径。

| 方法 | 操作 |
| --- | --- |
| 政府采购最低评标价法 | 先确认全部实质性要求满足。在第87号令框架下，按适用规则处理算术修正、政策价格扣除，以适用的价格口径由低到高排列。报价相同按法定规则处理并列与后续确定。 |
| 政府采购综合评分法 | 使用招标文件中公布的量化指标及权重，成员独立分项评价并汇总。价格按低价优先法计算，满足招标文件要求且经适用政策调整后用于评审的最低价为基准，计入总分的价格得分为基准价除以该评审报价再乘价格满分。第87号令规定货物项目价格分值占比不得低于30%，服务项目不得低于10%。执行国家统一定价标准和采用固定价格采购的项目，价格不列为评审因素。 |
| 经评审的最低投标价法 | 核对实质要求，根据项目发布的价格调整方法处理允许计价的偏差和其他调整，形成标价比较表。以经评审的投标价及规定的并列处理方式推荐候选人。 |
| 综合评估法 | 按公布的技术、商务、报价以及其他因素，对允许进入详评的投标评估。项目可能采用计分、折算或行业规定的具体基准公式，记录每个中间变量及偏差处理，按公布规则生成综合结果和排序。 |

## 评分与复算

1. 客观项按同一条件和相同证据口径，精确定位到文件。技术项按正式标准评审功能、性能、兼容性、实施、验收与服务等。对评分档次写出能回查的依据。资格、符合性和评分中的同一材料可各自按适用条件核查。
2. 先落实适用的中小企业、本国产品等政府采购政策，再按规定计算评审价或其他政策待遇。核实包件、折扣适用对象、叠加规则和政策生效时间。保留原报价、修正报价、评审价、各政策扣除及其顺序，合同价格按项目适用规则单列。
3. 综合评分核对分项上限、缺失值、超范围值、客观项一致性、权重、汇总和舍入口径。政府采购货物服务招标按第87号令在评标过程中保留最高与最低报价。负责人可检查计算与规定的复核情形，委员各自对专业判断负责。
4. 政府采购货物服务综合评分按评审得分由高到低，得分相同按投标报价由低到高，得分与报价相同并列。具体并列候选人的确定按第87号令及招标文件规定，文件未规定的按该令的随机抽取规则办理。招标投标制度按各自规则和项目文件处理并列、候选人数和排序。

## 其他采购方式

- 竞争性谈判按规定开展分别谈判，允许的实质性变动以书面同时通知参加谈判的供应商。按采购文件和谈判要求核对最后报价、实质响应和成交推荐。
- 竞争性磋商按规定组织磋商和最后报价。在满足实质要求的响应范围内执行公布的综合评分规则，核对采购文件变动授权、供应商数量和法定例外。
- 询价按采购文件一次报出不得更改的价格，从质量和服务均满足实质性要求的供应商中按适用规则推荐。单一来源记录协商及价格合理性。具体数量及例外从[官方来源](rules.md)核对。

## 复算示例

某政府采购服务包有三份满足实质性要求且可进入评分的报价。假设无政策价格扣除或价格修正，价格满分10分，报价分别为80、100、125万元，基准价为80万元。三家价格分是10、8、6.4。若技术商务汇总分别为75、79、81分，总分分别为85、87、87.4。工作底稿要保留评审价、价格分和技术商务分三列，在本例中按第三、第二、第一家的顺序排列。
