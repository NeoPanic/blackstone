# 适用规则、方法与职责

先记采购主体、资金和项目性质、标的与工程关联、采购方式、包号、监管主体、采购文件及有效补遗。以项目事实和现行规范确定路线，公告平台和文件标题仅作线索。地方、行业和平台细则影响流程时，核实是否适用、施行日期、过渡条款与项目文件。

| 项目情形 | 规则与评审方法 | 首要职责区分 |
| --- | --- | --- |
| 政府采购货物和服务公开或邀请招标 | 《政府采购法》、实施条例和财政部令第87号。最低评标价法或综合评分法。 | 第87号令第四十四条明确公开招标的资格审查由采购人或代理机构在开标后进行。评标委员会对符合资格的投标文件进行符合性审查和详细评标。邀请招标另核供应商产生与资格核验程序。 |
| 政府采购工程及与工程建设有关的货物、服务采用招标方式 | 《政府采购法实施条例》第七条转至《招标投标法》及其实施条例，同时执行适用的政府采购政策。 | 按招标人、资格审查委员会和评标委员会的职责及项目的资格预审或后审安排办理。 |
| 其他适用招标投标制度的项目 | 《招标投标法》及其实施条例以及现行行业规则。经评审的最低投标价法、综合评估法或依法允许的其他方法。 | 资格预审与资格后审分开核对。评标委员会按已发布规则评标并推荐候选人，定标按项目适用规定交有权主体。 |
| 政府采购采用竞争性谈判、竞争性磋商、询价、单一来源等 | 按该方式的专门规则。谈判或询价按相应实质响应和成交规则，磋商有书面变动、最后报价和综合评分，单一来源重点是协商和合理成交价格。 | 按采购方式核对小组组成、供应商数量、允许变更的内容、书面通知、报价轮次和成交规则。框架协议分别查征集入围、第二阶段成交规则。 |
| 企业自行采购 | 采购主体的有效制度、项目公告和文件。查明是否须适用招标投标相关法规。 | 按实际授权核对选聘、评审、复核和定标的责任人。 |
