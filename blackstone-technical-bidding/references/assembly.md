# 投标文件分册与组装

以项目给定的目录、模板和评审口径定册。先固定项目和包号、主体全称、统一社会信用代码、负责人及授权范围、产品版本和报价口径。各册引用同一份确认后的数据。

| 部件 | 编写与组装 |
| --- | --- |
| 封面、函件和索引 | 沿用格式，填项目编号、包号及主体。核对签署人、投标有效期、接收人、正副本和可选承诺。将目录和响应矩阵指向定稿页码或电子锚点。 |
| 资格证明 | 主体、信用、财务税收社保、行业资质、授权、联合体、制造商授权、声明函按条款装册。核对办理时间、有效期和签章。 |
| 商务部分 | 写交付期、地点、服务范围、付款、质保、知识产权、分包、违约和合同偏离。业绩及人员用索引挂证据，并核实是否满足同一评审项的全部条件。 |
| 技术偏离与参数响应 | 按原条款顺序写实际响应、指标、偏离及证据。标记样品、现场演示、原件备查或指定附件。 |
| 技术方案正文 | 对项目场景写需求、架构、部署、数据与接口、实施迁移、测试及验收、培训和运营服务。每个承诺给出做法、依赖、交付物和验证方式。 |
| 报价部分 | 对照报价表和开标一览表，核税率、币种、含税口径、数量乘单价、汇总、折扣、舍入、总价大小写和限价。厘清许可、设备、实施、运维、第三方服务、备件以及追加需求的计价方式。 |
| 项目专用附件 | 按条款准备保函或转账凭证、关联关系说明、政策声明、投标承诺、样品说明、演示材料、纸电版等。涉及暗标时遵循分册及匿名规则。 |

## 技术部分写到可验收

- 从评分项和验收条款倒推章节和证据。架构说明系统边界、部署拓扑、模块职责、网络与数据流。接口说明对接方向、责任方、字段与联调条件。
- 实施计划写明准备、联调、试运行、割接、回退和移交的进入条件、责任人、里程碑与交付物。技术服务写清服务时段、分级、响应与恢复口径。验收表将指标、测试环境、步骤、通过标准和证据连在一起。
- 设备项目核对型号、数量、配置、兼容性、安装调试和到货验收。软件和信息化项目核对授权计量、第三方组件、存量迁移和数据安全边界。工期、资源和费用同步落到计划、合同偏离表和报价。
- 排版后更新页码，原件证明在导出结果中可读。匿名技术册检查文字、页眉页脚、图片、二维码、水印、文件名、批注、修订和文档属性，依项目匿名规定判断。
- 检测报告、合同或验收证明含供应商名称、签名或印章时，核对是否安排在非暗标分册、独立附件或指定上传栏。项目要求的证明形式与匿名要求发生冲突时，提交书面澄清草稿，保留原件，依正式答复处理脱敏和分册。

## 报价和递交包

保留内部成本与外部报价各自的来源。可能进入异常低价审查的政府采购项目，备好成本构成、人工投入、报价对应的供应和履约依据，按文件要求判断何时入册。各包分别核对编号、金额、电子模板、签章对象和报价是否应单独递交。对纸质件核对密封标识和份数。
