# 异常低价、同品牌和程序例外

## 政府采购异常低价

先核对财库〔2026〕2号是否适用，以及采购文件载明的阈值和施行口径。通知要求采购文件明确以下启动情形。

| 触发情形 | 通知所列基准 |
| --- | --- |
| 与平均价比较 | 报价小于全部通过符合性审查供应商报价平均值的50%。 |
| 与次低价比较 | 报价小于通过符合性审查的次低报价供应商报价的50%。 |
| 与最高限价比较 | 报价小于最高限价的45%。未设定最高限价的，以采购项目预算金额作为最高限价。 |
| 专业判断 | 评审委员会认为报价过低，可能影响产品质量或诚信履约的其他情形。 |

前三项为严格小于。采购人可按项目实际提高前三项标准，最高不得超过65%。保留符合性审查通过的集合、原始报价和计算过程。用通知和采购文件确认报价口径，避免直接用计分阶段的政策评审价代入。

触发后在评审现场要求供应商在合理时间内解释并提供具体成本测算及必要证明，给予时间一般不少于30分钟。属于最高限价触发且已随投标或响应文件提交相关说明和必要证明的，现场可不重复提交。保留触发项、通知时间、给定时长、成本或市场证据、评委判断和处理。不能提供说明或证明，或提供的材料不能证明报价合理性的，按通知作无效投标或响应处理。第87号令第六十条的异常报价说明程序及项目规则一并核对。[财库〔2026〕2号](https://gks.mof.gov.cn/guizhangzhidu/202601/t20260121_3982332.htm)

## 招标投标制度中的低于成本

依法适用招标投标制度的项目，核对法律、实施条例和行业规则中关于低于成本、报价合理性说明和否决的条件。依据项目能力或行业证据核实成本说明，记录事实、要求、答复、理由和委员结论。政府采购通知的百分比规则按其各自的适用范围使用。

## 同品牌或核心产品

政府采购货物服务招标中，先确认核心产品及第87号令第三十一条的适用情况。最低评标价法下，同品牌由通过资格和符合性审查、报价最低的投标人参加评标，其他同品牌投标无效。综合评分法下，同品牌通过资格和符合性审查的投标人按一家计算，评审后得分最高的获得中标人推荐资格，其余不作为候选人。前一种方法发生同价或后一种方法发生同分时，由采购人或其委托的评标委员会按文件规定确定一家，文件未规定的随机抽取。保留品牌、核心产品、依据、计算阶段和判定结果。

## 人数、文件缺陷与异常线索

- 分时点登记递交、开标、资格、符合性和详评的参与数。政府采购货物服务公开招标中，投标人不足3家不得开标。符合专业条件或对招标文件作实质响应的供应商不足3家时，按《政府采购法》第三十六条废标，将理由通知所有投标人。应继续采购的，按第三十七条和第87号令第四十三条核对重新招标及依法变更采购方式的条件、程序和批准。第87号令第四十三条区分招标文件或程序存在问题与均无问题的处置。数量未达到程序要求时暂停评分和排名。[政府采购法第三十六条、第三十七条](https://www.gov.cn/gongbao/content/2002/content_61590.htm) · [财政部令第87号](https://tfs.mof.gov.cn/caizhengbuling/201707/t20170718_2652603.htm)
- 谈判、磋商、询价分别查小组组成、供应商数量和法定例外。招标投标制度中，投标人少于3个时不得开标，并按实施条例第四十四条重新招标。开标后否决部分投标而有效投标少于3个时，核对有效规则、是否明显缺乏竞争及是否需要否决全部投标或重新招标。
- 发现疑似串通、虚假材料、违法干预或利益冲突时，记录原件、来源和时间，由有权主体依认定条款和报告程序处理。普通相似性线索需和法定事实核对。评标期间出现泄密或异常接触时，按组织方程序留痕并报告。
- 规则冲突、平台故障、委员人数变化、匿名标识暴露等事件，记录发生时点、影响范围、适用条款及具备处置权的主体。恢复、停止、重新组织或其他处置均按适用规则执行。
