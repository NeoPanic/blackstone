# 适用规则与投标方式

## 先建立项目规则卡

记录采购人或招标人、采购标的、资金与立项性质、是否属于政府采购、是否属于工程或与工程建设有关的货物服务、采购方式、包号、监管部门、发布媒介及指定递交平台。只有标题或发布平台时，继续查公告正文、投标人须知和项目背景。规则适用有实质分歧时列出依据与影响，按可确认的部分继续编标。

| 情形 | 办理路线 |
| --- | --- |
| 政府采购货物和服务采用公开或邀请招标 | 《政府采购法》及其实施条例、财政部令第87号、适用的政府采购政策和采购文件。 |
| 政府采购工程及与工程建设有关的货物、服务采用招标方式 | 《招标投标法》及其实施条例。仍须执行适用的政府采购政策。工程关联性按《政府采购法实施条例》第七条判断。 |
| 其他工程建设项目或依法适用招标投标制度的项目 | 核对《招标投标法》及其实施条例、必须招标范围及规模、行业和地方有效规定、项目文件。依法必须招标项目的部分要求与其他招标项目不同。 |
| 政府采购采用竞争性谈判、竞争性磋商、询价、单一来源等 | 按对应办法和采购文件编响应文件，核对谈判或磋商通知、最后报价、询价一次报价等程序。单一来源按协商安排准备成本与履约资料。框架协议按财政部令第110号区分第一阶段征集和第二阶段成交。 |
| 企业和其他单位自行采购 | 查采购主体的有效制度和公告文件。实际属于依法适用招标投标制度的项目时，按该制度执行。 |

公开与邀请决定获取文件的入口和邀请资格。联合体与独立投标、单包或多包、线上与纸质递交是另外三个维度。按包核对是否允许联合体、分包、备选投标、兼投兼中以及人员和业绩是否允许跨包重复使用。规则允许时按项目文件准备联合协议、职责、资格、牵头授权和签章。

## 从原文确认的条款

- 核对文件发出和获取时间、现场踏勘或演示、提问及异议期限、澄清后是否顺延、保证金、投标有效期、截止和开标时间。记录原文的日或工作日、起算事件与当地时区。
- 政府采购货物服务招标按财政部令第87号第二十七条核对澄清修改。内容可能影响投标文件编制时，应在截止至少15日前书面通知所有已获取文件的潜在投标人，不足15日应顺延。用实际通知时点与新截止核算，换报价模板也应检查是否影响编制。澄清或修改涉及改变采购标的和资格条件时，记录原文并按项目程序处理。[财政部令第87号](https://tfs.mof.gov.cn/caizhengbuling/201707/t20170718_2652603.htm)
- 对依法必须招标项目，从招标文件开始发出至提交投标文件截止最短不得少于20日。按《招标投标法》第二十三条、第二十四条及实施条例第二十一条核对澄清修改通知和应顺延的情形。政府采购货物服务招标也须按《政府采购法》第三十五条核对20日期限，并按实施条例第三十一条和第87号令第十八条核对文件提供期限。分别核对取件截止、投标截止及补遗送达，保留依据。
- 国家法律、法规、部门规章、政策、地方和行业规定按适用范围、效力、施行时间及过渡条款核对。项目文件及有效澄清用于落实具体项目条件。发现条款与上位规则疑似冲突时留存两处原文并按窗口提出问题。
- 资格条件、评审因素、政府采购政策证明各有用途。根据当期项目核实中小企业、本国产品、节能环保等政策的适用条件、声明函及联合体和分包口径。以招标文件公布的评标办法判断报价、技术和商务证据的编制优先级。
